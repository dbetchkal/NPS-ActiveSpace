# Installation

See the [repository README](../README.md#installation) for install instructions.

Runtime dependencies are declared in [`pyproject.toml`](../pyproject.toml) at the repo root. Install with:

```
pip install -e .
```

or directly from GitHub:

```
pip install "NPS-ActiveSpace @ git+https://github.com/dbetchkal/NPS-ActiveSpace.git"
```
